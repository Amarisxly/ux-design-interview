# 设计面试陪练 · PWA 版

这个文件夹就是一个完整的网页 App，放到任意 HTTPS 网站上就能安装到手机桌面，离线也能用。

## 文件说明

- `index.html`：App 本体，题库、朗读、思路卡和笔记都在里面
- `manifest.webmanifest`：App 名称、图标、启动方式
- `sw.js`：离线缓存。第一次联网打开后，题库、字体和图标都会缓存下来
- `icons/`：桌面图标

## 三种上线方式（任选一种，都免费）

**1. Netlify Drop（最快，约 1 分钟）**
打开 https://app.netlify.com/drop ，把整个 `pwa` 文件夹拖进去，就会得到一个 https 网址。

**2. GitHub Pages**
新建仓库，上传这些文件，然后在 Settings → Pages 里选择 main 分支，等一两分钟就能访问。

**3. Vercel**
在 https://vercel.com/new 导入这个文件夹，不需要任何配置。

## 安装到手机

- **iPhone**：用 Safari 打开网址 → 点底部「分享」→「添加到主屏幕」
- **安卓 / 电脑 Chrome**：打开网址后，点页面右上角的「安装」按钮，或浏览器菜单里的「安装应用」

## 注意

- 必须是 https 网址才能安装和离线使用。直接双击打开 index.html 只能当普通网页用。
- 笔记和收藏保存在这台设备的浏览器里。换手机不会同步；清除浏览器数据会丢失。
- 朗读用的是手机自带的中文语音。装到桌面后用的是系统浏览器，中文语音通常比在其他 App 里打开更完整。
- 更新 App：替换 `index.html` 后，把 `sw.js` 第一行的 `dmi-v1` 改成 `dmi-v2`，用户下次打开就会拿到新版。
